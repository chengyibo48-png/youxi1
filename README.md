西游题材单人 2D 动作肉鸽。当前最新版为 **Godot 2.0 v11 Windows 本地版**。

## 新版内容

5 个取经角色，各有 6 件兵器，共 30 件可选兵器；26 名具名首领、37 个主题章节承接原著八十一难素材。角色采用不同资源积累与招式循环，通过普攻、蓄力、神通、绝技、法宝和闪避完成战斗，再用奖励、交易与修行改变后续打法。

行走使用 AI 辅助全身素材，攻击保留骨架与兵器约束。当前完整专业美术、正常全战役、实物手柄、多人试玩与全流程性能仍待验收；已有自动检查记录不等于真人体验验收。

## Windows 试玩

下载 Release 中的 Windows 包，完整解压后运行 `取经2.0.exe`。Windows 10/11 64 位，显卡支持 OpenGL 3.3，无需安装 Godot 或联网。

WASD 移动，左键普攻、右键蓄力、空格闪避；Q/E 神通，R 绝技，F 法宝，T 换兵器，C 召回，G 交互，Tab 路线，Esc 暂停。

## 从源码运行

安装 Godot 4.7 系列，导入 `godot-v2-combat/project.godot`，等待资源导入后运行。版本与制作记录见 [v11 接入说明](godot-v2-combat/ART_INTEGRATION_V11.md)。本次同步仅检查交付文件与资源引用，未重跑游戏测试。
