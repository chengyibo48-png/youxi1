# v11 素材接入与本地导出记录（2026-10-11）

按用户同意的阶段接入现有 AI 辅助全身步态，并继续首领动作、章节气氛制作。没有上线；原图、旧工程和既有检查记录保留。

## 已接入

- 五角色各四方向八帧步态，共 160 个全身姿态。基于透明连通轮廓建立缓存网格，去掉矩形裁切夹带的邻格碎片，固定各角色比例和脚底锚点；未修改源图像素。动作实际速度驱动帧率，起停渐变，攻击、闪避、受击和死亡返回原来的手臂与兵器约束。大兵器行走时背负，不伪造原素材不存在的双手握持。
- 26 名首领、95 个已存在招式的专属骨架时间轴，区分预备、释放和回收，受战斗时钟控制。转阶段和破势中止旧动作；腿长限制防止躯干抬升后脚底脱离。没有修改伤害和危险几何。
- 观音院／黑风山、黄风岭、五庄观三张原创 AI 辅助底画，累积六张章节专属地面、八类环境底画；37 章补各自光照与气氛定义，仍沿用现有剧情地标与可通行空间。
- 奖励房的静态地面在实例初始化时纳入子节点树，未进入场景树的实例也能完整释放，修复测试销毁时遗留的画布节点。

## 验证范围

`tests/art-v11-contracts.json`：1711 项接入检查通过，覆盖网格缓存、UV、五角色切换回实际招式、首领动作状态及现有 37 章入口出口。`tests/fullbody-v11-integrated-directions.png` 为实际渲染对照图；三张章节截图与首领对照图见 tests/art-v11-*。

五角色 / 五环境的 1080p、40 敌人、至少 120 投射物压力结果见 `tests/art-v11-performance.json`。同时记录全部显示帧、战斗推进帧及角色首次使用的前 40 帧；一个进程的首次使用不等于五次独立冷启动。测试恢复资源并使用无敌与高敌人生命，不是正常通关证据。

Windows 包使用匹配的官方 4.7.2 release 模板；模板来源与 CRC、SHA256 校验见 `build/template-cache/source.json`。导出只含本工程运行资源；工具、测试、缓存、Git 历史及上层目录不进入游戏包。交付目录包含运行说明、素材说明和引擎／字体授权。

实际最终压力结果：i7-12700H / RTX 3060 Laptop，五场各 1200 个战斗推进样本，全部显示帧 p95 为 10.329–11.324 ms，推进帧 p95 为 11.291–12.929 ms。首次场景前 40 帧最大值为 153.874–700.177 ms，仍有加载停顿，不认定冷启动及全流程性能达标。奖励房修复后 894 项场景／骨架回归通过，退出无原来的遗留节点警告。

独立验证：从导出目录用编辑器运行时直接读取 exe 内嵌包，五角色网格、26 首领、37 章、30 兵器及动态 JSON 完整，工具／测试／build／Git 等目录不存在，能进入战斗；这属于导出资源验证。另用实际 release exe 独立渲染主页五帧并正常退出，截图 `tests/export-home-smoke00000004.png`，不把编辑器包探测写成 release 正常通关。
