# 原创素材设计要求摘要

以下为设计要求摘要，并非逐字提示词。全部由内置图像生成辅助制作，没有输入商业游戏图片。

| 图集 | 要求与用途 |
|---|---|
| weapons.png | 五角色各六兵器，金属/木/玉/绳材质区分；握持、弹体、物品展示 |
| relics.png | 23种西游法宝与一个行囊，统一国风手绘；图标与陈设 |
| effects.png | 金棍、经印、土浪、沙刃、水剑分阶段表现；保留参考，核心攻击不使用整幅巨大覆盖 |
| rooms.png | 商肆、神龛、岔口、歇脚、经匣、锻炉、祭坛、关口；七种功能场景 |
| enemy-rig.png | 八类妖怪、九类可分离身体/兵器零件；关节动作，部分首领复用 |
| hero-rig.png | 五角色、十类身体部件：正背头、正背躯干、上臂、前臂、大腿、小腿、衣摆、挂饰 |
| terrain.png | 八类可行走地面，不烘焙高大障碍；国风材料质感 |

regions.json记录非等宽分区与透明边界，原PNG保留不重绘。运行时取区域、分层、约束关节；轨迹、颗粒与危险效果由招式代码驱动。二维插画与精灵，不是三维模型。
